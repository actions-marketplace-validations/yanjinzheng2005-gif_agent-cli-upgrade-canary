# Real-package validation

`openclaw-2026-08-17.example.json` records the public package versions and portable contract used for the first isolated observation.

The actual run used a local `openclaw-2026-08-17.local.json` with a Node 24 path. That file is intentionally gitignored. Public users should copy the example and point `runtime.nodeExecutable` at their own supported Node 22/24 binary.

No login, provider key, channel, gateway, or real user config is used.
